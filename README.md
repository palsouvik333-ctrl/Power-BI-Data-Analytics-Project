# Power-BI-Data-Analytics-Project
Interactive Power BI dashboard project for data analysis and visualization.

## Project Overview
This project focuses on data analysis and visualization using Microsoft Power BI. It provides meaningful insights through interactive dashboards and visual reports.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning

## Project Objectives
- Analyze the available dataset.
- Clean and transform data using Power Query.
- Create calculated columns and measures using DAX.
- Build interactive dashboards.
- Identify key trends and insights.

## Key Features
- Interactive dashboard
- KPI cards
- Data visualization
- Filters and slicers
- Business insights

## Project Files
- PROJECT01.pbit – Power BI report template.
- Screenshots – Dashboard previews.

## How to View
1. Download the project file.
2. Open it using Microsoft Power BI Desktop.
3. Connect the required data source if prompted.
4. Explore the dashboard.
